# MazeGame Server

MazeGame 專題的後端 Server，使用 **Spring Boot** 開發，提供前後端資料交換所需的 API 服務。

本專案採用 RESTful API 架構，整合使用者驗證、權限管理以及資料庫操作功能。

---

## 🛠 Tech Stack

### Backend

- Java
- Spring Boot
- Spring Security
- Spring Data JPA

### Database

- MySQL

### Authentication

- JWT (JSON Web Token)

### Build Tool

- Maven

---

## ✨ Features

### 🔐 Authentication

- 使用 Spring Security 建立驗證機制
- 使用 JWT Token 進行身份驗證
- 控制 API 存取權限

### 🌐 RESTful API

- 提供前端功能所需的 API 服務
- 使用 Controller 處理 HTTP Request
- 採用分層架構管理程式邏輯

### 🗄 Database

- 使用 Spring Data JPA 進行資料庫操作
- 透過 Entity 管理資料模型
- 使用 Repository 進行資料存取

### 🖥 Backend Management API

- 提供後台功能所需 API
- 支援資料查詢與管理操作
